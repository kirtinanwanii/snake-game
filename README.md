# Snake and Food Game

A desktop-based Snake game developed using Python and Tkinter. The game allows players to control a snake, collect food, and increase their score while avoiding collisions with the walls and their own body.

## Overview

This project implements the classic Snake game with a graphical user interface. It uses Tkinter for rendering the game window, handling keyboard inputs, and managing game updates.

The interface features a custom dark theme with a subtle grid layout.

## Features

- Real-time snake movement
- Random food generation
- Dynamic score tracking and high-score display
- Wall and self-collision detection
- Pause and resume functionality
- Game restart functionality
- Keyboard input using arrow keys and WASD
- Customizable game colors and dimensions

## Technologies

- **Language:** Python
- **GUI Framework:** Tkinter
- **Standard Library:** random

## Controls

| Key | Function |
|---|---|
| Arrow Keys | Control snake movement |
| W, A, S, D | Alternative movement controls |
| P / Space | Pause or resume the game |
| R | Restart after Game Over |

## Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/kirtinanwanii/snake-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd snake-game
   ```

3. Run the application:

   ```bash
   python main.py
   ```
